# Inkwright's Scriptorium

Inkwright's Scriptorium is a desktop app for animated illuminated manuscripts: type a line, pick a script, and watch it written out with a gold-and-silver pen.

This repository is for **bug reports** and **feature requests**. The app itself is not hosted here.

## Report a bug

1. In the app, choose **Help → Report a problem…** (or the link in Settings, or the button on an error). The app prepares a short report with the version, script, language, system, and last error. It never includes your document text, your OpenRouter key, or your folders.
2. Click **Open issue page…**. A form opens in your browser with those details filled in. Check it, add anything you would like, and submit.
3. If the link would be too long, the app copies the report and opens a blank form — paste the report into the form.

You can also open a bug report directly: [Report a bug](https://github.com/IMBaron/inkwrights-scriptorium/issues/new?template=bug_report.yml).

## Request a feature

In the app, choose **Help → Request a feature…**, or the link in Settings, or [open a feature request](https://github.com/IMBaron/inkwrights-scriptorium/issues/new?template=feature_request.yml).
